# SLOW Concreto Circular | Sitio web editorial

Sitio estático (HTML, CSS y JS). Sin dependencias ni build.

Páginas: index.html (inicio), catalogo.html (mosaico con filtros y visor), proceso.html, contacto.html (formulario a WhatsApp), 404.html.

Publicar en GitHub Pages: Settings > Pages > Deploy from a branch > main / (root). Dejar vacío "Custom domain".
